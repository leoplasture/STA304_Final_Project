# Framework Quirks

Append-only durable file for framework-layer pitfalls (validator path quirks, closure-protocol gotchas, anything that cannot or will not be fixed in code and that future quests should know about before exercising the same surfaces).

Each entry should name the surface, the symptom, and the workaround in 2-5 lines. Stage skills (idea, decision, finalize) instruct agents to read this file before committing to a route that would touch the relevant surface.

If a quirk should instead be fixed at the framework level, file an issue and fix the code; do not add it here as a permanent shim.
